# Initial Findings

## Objective
Verify that the webcam can be initialized using OpenCV and establish the foundation for future computer vision tasks.

## Environment
- Operating System: Windows 11
- Python: 3.14.6
- OpenCV: 5.0.0
- IDE: Visual Studio Code
- Camera: USB Webcam

## Research Summary
- Learned the basics of computer vision and OpenCV.
- Understood how OpenCV captures video frames from a webcam.
- Researched object detection and bounding boxes for future development.

## Testing Performed
- Successfully initialized the webcam.
- Displayed a live video feed.
- Captured multiple test images.
- Recorded a test video.
- Verified that the webcam released correctly after closing the application.

## Challenges Encountered
- Python interpreter mismatch between the global installation and the virtual environment.
- File path issues when running Python scripts.
- Git repository initialization and branch setup.

## Solutions
- Activated the virtual environment before running Python scripts.
- Executed scripts from the correct project directory.
- Configured Git user information and pushed the initial project to GitHub.

## Conclusion
The development environment is fully configured and functioning correctly. The webcam successfully captures live video, images, and recorded video. The project is ready to move to the next phase: object detection and bounding box implementation.
